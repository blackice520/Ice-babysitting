# ICE-Babysitting 2.1.1

> 打游戏时看攻略视频的小窗浏览器 —— 全局热键 + 手柄控制 + 鼠标穿透
> 纯本地运行，无卡密、无服务器、无联网验证

## 下载哪个？

| 文件 | 适合谁 | 说明 |
| --- | --- | --- |
| **`ICE-Babysitting-Setup-2.1.1.exe`** | 普通用户（推荐） | 安装向导：可选安装位置、自动创建开始菜单与桌面快捷方式、自带卸载程序 |
| **`ICE-Babysitting-2.1.1-win64-portable.zip`** | 想免安装 / 放 U 盘 | 解压后双击 `ICE-Babysitting.exe` 即用，**必须保留整个文件夹**（程序依赖同目录的 `_internal`） |

## 运行要求

- Windows 10 / 11（64 位）
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) —— Win11 与绝大多数 Win10 已自带
- 启动时会请求管理员权限：游戏常以管理员运行，程序需要同权限才能接管全局热键

> 首次启动若杀毒软件报毒，属于 PyInstaller 单文件程序的常见误报，加白名单即可。

## 这一版有什么

- **长按倍速**：快进键短按快进 5 秒、按住不放变 3 倍速、松手恢复原速（B站 手感）
- **自动开启声音**：进视频页自动解除静音，可在「设置 → 播放选项」关闭，改完立即生效
- **手柄支持**：XInput 映射播放 / 暂停、快进快退、隐藏、穿透，设置界面可视化改绑
- **沉浸穿透**：一键隐藏导航栏 + 鼠标穿透，状态栏常驻显示恢复热键
- **浅色圆角界面**：Win11 原生窗口圆角，白底不挡视线
- **跨屏拖动修复**：多显示器不同缩放时不再"越拖越大"，窗口几何带自愈
- **按键去重**：按住不放不再疯狂连发
- **数据自动迁移**：旧版本把数据放在程序目录下的，首次启动自动搬到用户目录，不覆盖已有数据

完整变更见 [CHANGELOG.md](../CHANGELOG.md)。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| <code>`</code> | 播放 / 暂停 |
| `6` | 短按快进 5 秒 / 长按 3 倍速 |
| `5` | 快退 5 秒（按住连发） |
| `9` | 隐藏 / 显示窗口 |
| `0` | 鼠标穿透（再按恢复） |
| `Ctrl+Space` | 最大化 / 还原 |

全部可在「设置」里改绑，点输入框直接按键盘即可录制。
